## 🗂️ About the Project

This repository holds the **Google Drive links** to my complete project archive — full source code, project reports, abstracts, base papers and datasets that are too large to store directly on GitHub.

## ✨ Key Features

- 📦 Complete **source code** bundles
- 📄 Project **reports, abstracts & base papers**
- 📊 Large **datasets** and trained models
- 🔗 All links listed in the `DRIVE LINKS` file

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Storage | Google Drive |
| Index | `DRIVE LINKS` text file |

## 📥 How to Use

1. Open the **`DRIVE LINKS`** file in this repo.
2. Click the link for the project you need.
3. Download and follow that project's README to run it. 🚀
